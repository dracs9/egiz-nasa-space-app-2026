# Egiz: земные двойники Луны и Марса

Командный репозиторий для **NASA Space Apps Challenge 2026**. Egiz — рабочее название (каз. «егіз», близнец). Финальное название выберем вместе с маркетологом.

| | |
| --- | --- |
| **Хакатон** | 14–15 ноября 2026, Астана, школа «Мирас», очно |
| **Челлендж** | [Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars](https://www.spaceappschallenge.org/2026/challenges/identify-earth-locations-that-analog-the-permanent-moon-base-locations-and-mars/) |
| **Команда** | 4 вайб-кодера, геолог, маркетолог |
| **Статус** | Готовимся. Полное условие челленджа выйдет 28 октября |

## Что делаем

Пользователь выбирает место на Луне или Марсе и что хочет там испытать: ровер, геологию, добычу ресурсов или посадку. Сервис по открытым данным NASA находит на Земле самые похожие места, объясняет, чем они похожи и чем нет, и показывает новых кандидатов в Казахстане.

Подробно: [docs/02-product.md](docs/02-product.md).

## Прочитать всем до 28 октября

1. **До 14 ноября нельзя начинать работу над проектом.** Ни кода, ни обработки данных, ни дизайна. Можно учиться и заводить аккаунты. Поэтому в репозитории пока только документы.
2. **Демо — видео до 30 секунд** с английскими субтитрами **или до 7 слайдов** на английском. Не 2 минуты.
3. **Данные NASA обязательны** для глобальных наград.
4. **ИИ можно**, но каждое использование записываем в [журнал ИИ](docs/ai-log.md).
5. **Ссылки на проект и демо должны открываться без логина.** Перед подачей делаем репозиторий публичным.
