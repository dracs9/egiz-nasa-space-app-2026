# Как работаем

## Главное правило NASA

До 14 ноября 2026 в этом репозитории только документы. Код, обработку данных и дизайн проекта начинаем на хакатоне. Тренироваться можно в своих отдельных папках на посторонних примерах.

## Что где лежит

- `README.md` — главная страница и навигация.
- `docs/` — все документы команды. Источник правды.
- `prompts/` — промты для ИИ-инструментов.
- `.github/` — шаблон pull request.

С 14 ноября добавятся папки с кодом: [docs/05-architecture.md](docs/05-architecture.md#структура-репозитория).

## Git

1. Перед началом работы: `git pull`.
2. Работаем в своей ветке, например `git switch -c web/map-layer`. Префикс ветки — модуль: `earth/`, `planets/`, `engine/`, `web/`, `docs/`.
3. Коммиты маленькие, сообщение на английском: `engine: add slope metrics`.
4. Открываем pull request в `main`. Сливает тех-лид (кодер D).
5. В `main` напрямую не пушим и не делаем `force push`.

## Что не коммитим

- Ключи API, токены, пароли, `.env`. Если ключ попал в коммит, сразу говорим тех-лиду и перевыпускаем ключ.
- Большие файлы данных: GeoTIFF, архивы, сырые снимки. Они лежат в `data/raw/` и не попадают в git. В репозиторий кладём только маленькие обработанные JSON.

## ИИ

- Пользоваться можно и нужно.
- Каждое заметное использование записываем в [docs/ai-log.md](docs/ai-log.md): кто, каким инструментом, для чего.
- Картинки и видео от ИИ идут с видимой пометкой «AI-generated». Без логотипов и символики NASA.
- Числа и научные утверждения от ИИ проверяем. Всё научное подписывает геолог.
