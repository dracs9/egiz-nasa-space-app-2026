# Казахстан: кандидаты и эталоны

Владелец: MEMBER_E. Статус: гипотезы для проверки на хакатоне. В v2 Казахстан — режим (P1: EARTH-07, WEB-10): движок считает, какую долю кампании могут взять квадраты `KZ_`, рядом с глобальной кампанией. Главный результат — глобальный.

> Мангистау, Устюрт и другие районы — кандидаты, а не доказанные аналоги. Сходства на фотографиях недостаточно. Каждый кандидат проходит через движок (ENG-03) и научную проверку (SCI-05), досье пишем только по числам из results.json (SCI-08).

## 2. Про Луну честно

Для южного полюса Луны Казахстан, скорее всего, слабый аналог: нет полярного низкого Солнца и такого холода. Лучшие земные аналоги там — Арктика, Антарктида, Исландия, вулканические поля. Если движок покажет это сам (гипотеза H3), это доказательство, что метод не подгоняли под ответ, — и сильный честный момент для жюри.

## 3. Эталоны для проверки метода (v1; в v2 — места практики по задачам)

Пары, которые NASA и агентства уже используют. В v2 проверка идёт не «пара целиком», а «площадка × задача испытания»: место практики должно попасть высоко в рейтинг соответствия именно для той задачи, ради которой его использовали (E3). Окончательный список, правила исключения и источники — `practice_sites.csv` (SCI-03) по [VALIDATION_PROTOCOL E3](VALIDATION_PROTOCOL.md); черновой список — заметка PREP-15.

- Долина Смерти ↔ Utopia Planitia (Viking 2): здесь команда Mars 2020 тренировала обход препятствий (NASA Planetary Analog Explorer).
- Килауэа, Гавайи ↔ базальты Луны (Apollo 15, Hadley Rille).
- Атакама ↔ сухие почвы Марса.
- Исландия ↔ лёд Луны; Исландия (Викурсандур) ↔ рябь Марса — вероятно, исключается по правилу масштаба < 200 м.
- Озеро Салда, Турция ↔ кратер Jezero — вероятно, исключается как химическая аналогия (карбонаты, вода).
- Кратер Хотон, о. Девон, Канада ↔ Марс (Haughton-Mars Project).
- Кратер Рис, Германия: здесь тренировался экипаж Apollo 14.
- Вулканическое поле Сан-Франциско, Аризона: полевые испытания выходов Artemis (JETT).

Источник первых пар: [NASA Planetary Analog Explorer](https://science.nasa.gov/solar-system/analog-explorer/). Остальные MEMBER_E подтверждает источниками NASA, агентств или статей.

## 4. Шаблон досье (SCI-08, P1, на английском)

Геолог заполняет на каждого кандидата из топа. Файл `data/curated/dossiers/KZ_<id>.md`.

| Поле | Что пишем |
| --- | --- |
| Name and coordinates | Название, координаты центра квадрата, ID квадрата |
| Analog of | Цель на Луне или Марсе и задача испытания (O1…O5, M1…M4) |
| What matches | Атрибуты с высоким f и их значения из results.json (кандидат и цель) |
| What does not match | Атрибуты с низким f, потолки задач и физические разрывы из реестра «Earth cannot test» |
| Geology (P1) | Теги из `geology_tags.csv` и источники |
| Logistics | Как добраться, сезон, ближайший город (справочно) |
| Field measurements | Что замерить: состав солей, плотность грунта, размер зёрен и т. п. |
| Status | «Candidate — requires field verification» |
| Sources | Данные (ID наборов) и статьи |
