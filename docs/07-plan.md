Конкурсный проект создаём во время хакатона; до старта изучаем предмет и инструменты.

## Два дня хакатона

| Когда | Что делаем |
| --- | --- |
| **14 ноября, первый час** | Выбираем основной сценарий, участки и признаки. Распределяем задачи. Схема JSON, репозиторий, фейковые данные |
| **14 ноября, к вечеру** | Рабочая цепочка: реальные данные → расчёт → результат на карте |
| 14 ноября, вечер | Геолог проверяет топ-кандидатов, маркетолог пишет сценарий видео |
| **15 ноября, до 12:00** | Проверяем выводы, улучшаем интерфейс. В 12:00 заморозка функций |
| 15 ноября, после 12:00 | Только баги, досье, видео, страница проекта |
| **15 ноября, за 3 часа до дедлайна** | Подаём проект, проверяем ссылки в режиме инкогнито |

## Риски

| Риск | Что делаем |
| --- | --- |
| Уклоны посчитаны на разном разрешении | Одно разрешение и одна функция для всех трёх тел |
| ИИ выдал красивые, но неверные числа | Проверки на известных фактах: Бэдуотер в Долине Смерти −86 м, Карагие −132 м. Геолог подписывает каждый вывод |
| Всё сломалось при сборке в последний час | Схема JSON в первый час, фейковые данные, один интегратор, заморозка в 12:00 второго дня |
| Демо не открылось у судей | Статический сайт, записанное видео, скриншоты. Проверка ссылок в инкогнито |
| Слабый Wi-Fi на площадке | Расчёты в облаке Earth Engine, окна COG вместо скачиваний, мобильный интернет в запасе |
| Нарушение правил подачи | Раздел про ИИ, пометки на ИИ-картинках, без логотипов NASA, видео и слайды на английском |
