# 24 концепции

Дата: 10.10.2026. Цель — разные научные идеи, а не 20 вариантов одной карты. Для каждой концепции: проблема, пользователь, зачем, что нового, данные, алгоритм (что именно считается), ожидаемый результат, выполнимость за хакатон (В — высокая, С — средняя, Н — низкая), проверка, визуализация, связь с челленджем, риски, ограничения, отличие от существующего. Оценка и отбор — [CONCEPT_EVALUATION](CONCEPT_EVALUATION.md).

---

### C01. Поисковик аналогов (Egiz v1)

- **Проблема / пользователь:** «какое место Земли похоже на цель» / полевые учёные.
- **Новое:** профили-веса, обрезка различий.
- **Данные:** Copernicus DEM, MODIS LST, GPM IMERG, WorldCover; LOLA, MOLA/HRSC.
- **Считаем:** `score = 100·exp(−Σw·d²/Σw)` по 9 признакам на базе 200 м.
- **Результат:** рейтинг ~10 тыс. квадратов. **Выполнимость:** С.
- **Проверка:** слепое восстановление известных пар — вероятен провал (аналогии держатся на свойствах вне признаков).
- **Визуализация:** карта-тепловая, Twin view. **Связь:** прямая.
- **Риски / ограничения:** «любая пустыня похожа»; произвольные базы и пороги.
- **Отличие:** слабое — типовая идея сотен команд.

### C02. Матрица соответствия по задачам испытаний

- **Проблема:** соответствие аналога зависит от цели использования (Lee 2010, Stern 2025), а инструменты дают общий балл.
- **Пользователь:** планировщики испытаний (роверы, EVA, посадка, ISRU).
- **Новое:** количественные функции соответствия для атрибутов каждой задачи; пороги и базы — из критериев NASA (100 м < 10°, 2 км < 20°, LTV 20°).
- **Данные:** DEM трёх тел, MODIS, IMERG, WorldCover.
- **Считаем:** для атрибута — функция соответствия `f∈[0,1]` (совпадение, «не больше», «не меньше»); для задачи — взвешенное геометрическое среднее `F_o`.
- **Результат:** для каждой площадки — какие задачи она закрывает и насколько. **Выполнимость:** В.
- **Проверка:** ранги мест, которые NASA использовала именно для этой задачи; базовые линии.
- **Визуализация:** матрица «площадки × атрибуты» с раскрытием значений. **Связь:** прямая («characterize»).
- **Риски:** допуски задаёт эксперт. **Ограничения:** геология только экспертно.
- **Отличие:** заметное.

### C03. Оптимизатор кампании испытаний

- **Проблема:** ни одна площадка не воспроизводит цель целиком, а программы испытаний собирают из нескольких мест «вручную».
- **Пользователь:** руководители аналоговых кампаний, планировщики миссий.
- **Новое:** формальная задача максимального покрытия — наименьший набор площадок, который вместе лучше всего покрывает задачи миссии. Публикаций с таким методом мы не нашли.
- **Данные:** выход C02.
- **Считаем:** `C(S) = Σ_o W_o·max_{e∈S} F_o(e) / ΣW` → максимум при `|S| ≤ k`; точный перебор на коротком списке, жадный поиск на всём пуле, фронт «k — покрытие».
- **Результат:** 1–3 площадки с ролями и процент покрытия по задачам. **Выполнимость:** В (математика простая).
- **Проверка:** точность против полного перебора; устойчивость к весам и бутстрэпу пула.
- **Визуализация:** карточка кампании, столбики покрытия, фронт. **Связь:** «for future bases or landing sites» — операционно.
- **Риски:** «процент покрытия» могут счесть абстрактным. **Ограничения:** покрытие не равно пригодности.
- **Отличие:** сильное.

### C04. Окна лунного освещения на Земле

- **Проблема:** NASA имитирует освещение южного полюса ночью прожектором (JETT3, JETT5).
- **Пользователь:** тренировки EVA, тесты навигации и камер при низком Солнце.
- **Новое:** поиск мест и недель, где естественное Солнце держится в диапазоне лунного полюса (2–7°) и обходит горизонт; сравнение доли тени по DEM при той же высоте Солнца.
- **Данные:** положение Солнца (алгоритм NOAA, проверка по astropy); Copernicus 30 м; DEM PGDA 5 м → 30 м; снег MODIS (P1).
- **Считаем:** часы в день с `0 < h ≤ h_max(цель)` по месяцам; «обход горизонта»; доля тени `sf(h, az)` по DEM.
- **Результат:** календарь окон и площадки с похожими тенями. **Выполнимость:** С (тени — P1).
- **Проверка:** точность Солнца против эталона; аналитические тесты теней; (P2) сверка с освещённостью PGDA.
- **Визуализация:** «То же Солнце» — две местности с одинаковым Солнцем, анимация теней. **Связь:** Moon Base — прямо.
- **Риски:** снег, рассеянный свет атмосферы. **Ограничения:** только Луна.
- **Отличие:** очень сильное.

### C05. Реестр разрывов («потолок Земли»)

- **Проблема:** честно показать, чего Земля не даст, и чем это заменить.
- **Пользователь:** инженеры испытаний.
- **Считаем:** потолок `max_e f_i(e)` для каждого атрибута задачи; атрибуты с потолком < 0,1 → разрыв; физические разрывы (гравитация, вакуум, радиация, холод PSR) → альтернативные средства (камеры, параболические полёты, прожекторы).
- **Результат:** таблица «разрыв → чем закрыть». **Выполнимость:** В.
- **Проверка:** логическая (потолок по всему пулу). **Визуализация:** панель разрывов. **Связь:** «characterize».
- **Отличие:** сильное как дополнение.

### C06. Атлас спектров шероховатости

- **Проблема:** сравнить рельеф тел на многих масштабах.
- **Считаем:** уклоны и среднеквадратичное отклонение на базах 100 м – 5 км, показатель Херста.
- **Данные:** DEM трёх тел. **Выполнимость:** В. **Проверка:** аналитические поверхности.
- **Визуализация:** кривые «база — шероховатость». **Отличие:** методы известны (Shepard 2001), новизна в применении.
- **Риски:** судьям трудно понять.

### C07. Операционный «отпечаток» маршрутов ровера

- **Проблема:** похожесть рельефа для ровера — это похожесть маршрутов.
- **Считаем:** кратчайшие пути при ограничении уклона 20° между случайными парами точек; распределения извилистости и недостижимости.
- **Данные:** DEM. **Выполнимость:** С (графы на окнах 20 км — быстро).
- **Проверка:** синтетика; сравнение с уклонами. **Визуализация:** пути на двух местностях.
- **Ограничения:** масштаб камней не виден. **Отличие:** сильное, но узкое.

### C08. Аналоги опасностей посадки для систем HDA

- **Проблема:** тестировать автоматический выбор места посадки на похожих опасностях.
- **Считаем:** статистика уклонов и неровностей на масштабе посадочной опоры.
- **Данные:** нужны DEM метрового масштаба — для Земли глобально нет.
- **Выполнимость:** Н. **Отличие:** сильное, но без данных.

### C09. Минералогические аналоги

- **Проблема:** подобрать места с похожими минералами.
- **Считаем:** сходство наборов минералов: EMIT (Земля, 10 минералов, 60 м) против литературных обнаружений CRISM и OMEGA (Марс).
- **Выполнимость:** Н–С: EMIT нет в GEE, идёт переход на версию 2.
- **Проверка:** сравнение с известными местами. **Отличие:** сильное.
- **Риски:** сложность данных за один день.

### C10. Планировщик сезонов по температурам

- **Считаем:** месячные температуры поверхности MODIS против режимов цели; окна «холодно и сухо».
- **Выполнимость:** В. **Ограничения:** Луна вне диапазона Земли. **Отличие:** среднее (входит атрибутом в C02).

### C11. Поиск источников имитаторов грунта

- **Считаем:** геологическое соответствие (базальтовый пепел, анортозит) по геологическим картам.
- **Данные:** нет глобальной открытой сопоставимой карты пород в GEE (GLiM — вне каталога).
- **Выполнимость:** Н–С. **Проверка:** известные источники (Merriam, Pu'u Nene, Saddleback).

### C12. Рейтинг с учётом неопределённости

- **Считаем:** Монте-Карло по погрешностям DEM (клоны PGDA) и диапазонам параметров целей → интервалы рангов.
- **Выполнимость:** С. **Отличие:** усиливает любую концепцию; используем как слой (P1–P2).

### C13. Самообучаемые эмбеддинги DEM трёх тел

- **Считаем:** автоэнкодер на патчах DEM, поиск ближайших соседей.
- **Выполнимость:** Н (обучение и проверка за день). **Проверка:** слабая. **Риски:** чёрный ящик.

### C14. Сопоставление инвентарей форм рельефа

- **Считаем:** детекция кратеров, конусов, дюн и сравнение распределений.
- **Выполнимость:** Н. **Риски:** детекторы для трёх тел.

### C15. Цифровой двойник и VR

- **Что делает:** 3D-прогулка по цели и аналогу. **Выполнимость:** С. **Наука:** вторична.

### C16. Аналоги затенения связи рельефом

- **Считаем:** зоны прямой видимости в окнах DEM. **Связь:** слабая (на Земле связь не проблема).

### C17. Площадки для испытаний солнечных батарей при низком Солнце

- **Считаем:** окна долгого низкого Солнца для вертикальных панелей (как на «пиках вечного света»).
- **Выполнимость:** В (часть C04). **Отличие:** сильное, узкое. **Решение:** включено в C04 как сценарий использования.

### C18. Объединённый каталог аналогов

- **Что делает:** сводит списки NASA и ESA в открытый набор данных с атрибутами ДЗЗ.
- **Выполнимость:** С. **Проверка:** полнота. **Отличие:** вклад в данные, слабое демо.

### C19. Исследовательский ассистент с цитатами (RAG)

- **Что делает:** отвечает по литературе со ссылками. **Риски:** выдуманные факты, нечего проверять числами. **Выполнимость:** С.

### C20. Аналоги для марсианских зон высадки людей (ISRU и строительство)

- **Считаем:** критерии зон высадки (лёд, уклоны, широта) → земные аналоги вечной мерзлоты.
- **Выполнимость:** С. **Отличие:** среднее (частный случай C02 для Марса).

### C21. Мониторинг стабильности площадок

- **Считаем:** ряды Landsat и SAR — меняется ли площадка. **Связь:** косвенная.

### C22. Подбор земных местностей для обучающих данных автономии

- **Считаем:** статистика рельефа как мера близости доменов для обучения навигации ровера. **Проверка:** нужна модель автономии — нет. **Выполнимость:** Н.

### C23. Логистический оптимизатор

- **Считаем:** стоимость доступа и сезоны. **Данные:** нет открытых данных о разрешениях. **Решение:** логистика — справочно.

### C24. Платформа полевой проверки силами энтузиастов

- **Что делает:** сбор фото и измерений. **Выполнимость:** Н за хакатон. **Наука:** отложенная.

## Что получилось

Сильные и разные научные идеи: **C02** (соответствие по задачам), **C03** (кампания), **C04** (окна освещения), **C05** (разрывы), **C07** (маршруты), **C06** (спектры шероховатости), **C09** (минералогия). C02, C03, C04 и C05 образуют одну цепочку: соответствие → кампания → освещение как атрибут задачи → разрывы. Оценка — в [CONCEPT_EVALUATION](CONCEPT_EVALUATION.md).
