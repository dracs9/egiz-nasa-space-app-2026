# Оценка концепций

Дата: 10.10.2026. Сначала три раунда критики сильнейших вариантов с трёх позиций, затем взвешенная матрица со штрафами за риск. Записаны альтернативы, возражения, доказательства и решения — без «стенограмм рассуждений».

## 1. Кандидаты в финал

- **F1 — Egiz v2 полный:** C02 + C03 + C04 + C05 (соответствие по задачам, кампания, окна освещения, разрывы).
- **F2 — C04 отдельно:** окна лунного освещения.
- **F3 — C03 без освещения:** C02 + C03 + C05.
- **F4 — C02 + C05:** соответствие по задачам и разрывы.
- **F5 — C07:** маршруты ровера.
- **F6 — C01:** поисковик v1 (контроль).

### F5. Маршруты ровера

Учёный: интересно и физически осмысленно. Инженер: графы на 50 окнах — реально. Судья: узко, трудно показать за 30 секунд. Решение: идея на будущее; кратко упомянуть в «что дальше».

### F6. Поисковик v1

Учёный: проверка, скорее всего, провалится. Судья: типовая идея. Решение: не использовать как центральный продукт. Оставить как вид «кандидаты по одной задаче» внутри F1.

## 3. Взвешенная матрица

Обоснование ключевых оценок:

- **F1, наука 4:** физические признаки на базах NASA, явные функции соответствия; не 5, потому что допуски экспертные, а геология курируемая.
- **F1, новизна 5:** кампания как задача покрытия и естественные окна освещения в литературе не найдены (SCIENTIFIC_PRIOR_ART §3, §5).
- **F1, проверка 4:** точность Солнца и оптимизатора проверяется численно; восстановление практики по задачам — с малой выборкой.
- **F1, выполнимость 3:** P0 ≈ 41 ч при 52 ч в сценарии S1 — впритык. Отсюда **штраф −6**: доступ к DEM, GEE, интеграция за один день.
- **F2, челлендж 3:** охватывает только освещение Луны. **Штраф −5:** узость и оговорки по снегу и атмосфере.
- **C09, штраф −8:** EMIT нет в GEE, идёт переход на версию 2, обработка CRISM не уложится в день.
- **C13 и C19:** низкая проверяемость — главный критерий для Best Use of Science.
