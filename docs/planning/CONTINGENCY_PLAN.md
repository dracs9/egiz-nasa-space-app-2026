# План на случай отставания и сбоев

Владелец: MEMBER_A (решения по объёму), MEMBER_E (научные решения), MEMBER_F (подача). Принцип: **при отставании режем объём по заранее записанному списку, а не «ускоряемся»**. Каждое включение запасного пути — одна строка в DECISIONS.md (время, ворота, что отрезано).

## 1. Принципы

1. Ворота (§2) проверяются по факту в указанное время. Если критерий не выполнен, действие включается **без обсуждения**; обсуждать можно только отмену уже принятого действия.
2. Сначала режем P1 и украшения, потом P0 по списку §3; никогда не режем: пререгистрацию, честность ограничений, проверку утверждений, приватность, подачу.
3. Отрезанное не удаляем из реестра: задача получает статус BLOCKED с причиной «снято воротами Gx» или остаётся BACKLOG с записью в DECISIONS.
4. Любой сбой, который не описан здесь, решает владелец ворот за 5 минут и записывает решение.
