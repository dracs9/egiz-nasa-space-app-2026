# Журнал прогресса

Статусы задач живут в `project/tasks.json` — смотрите `python3 tools/tasks.py status` и `python3 tools/tasks.py next MEMBER_X`. Здесь — короткие записи о сделанном, чтобы следующая сессия Claude Code или другой участник могли продолжить.

**Правила записи**

- Каждый пишет **только в свой раздел**, новые записи — в конец раздела. Так параллельные ветки не конфликтуют в git.
- Формат: `ДД.ММ ЧЧ:ММ · ID задач · что сделано · чем проверено (команда → результат) · что дальше · блокеры`.
- Без имён и персональных данных: только MEMBER_X.
