# Почасовой план хакатона

Владелец: MEMBER_A (ведёт время), MEMBER_F (напоминания в #general). Время — Астана (UTC+5). Окна взяты из `project/tasks.json` (поле `window`); если меняете окно, меняйте его в реестре, затем `python3 tools/tasks.py render`. Модель выполнимости этих окон — [CRITICAL_PATH_AND_DEPENDENCIES §3–4](CRITICAL_PATH_AND_DEPENDENCIES.md); что делать при отставании — [CONTINGENCY_PLAN](CONTINGENCY_PLAN.md).

## 0. Правила, которые действуют весь хакатон

1. **Ничего до 09:00 субботы.** До старта — только PREP-задачи (`tools/tasks.py` не даст начать HACK раньше).
2. **Оценки — это инженерное время**: написать, запустить на настоящих данных, проверить, отревьюить, слить. Claude Code генерирует код за минуты; час уходит на то, чтобы убедиться, что он делает правильное. Задача не DONE, пока не выполнены команды проверки из её карточки.
3. **Одна задача в работе на человека** (максимум две, если одна ждёт расчёта GEE). Перед началом: `python3 tools/tasks.py set ID IN_PROGRESS`; после: `set ID DONE --evidence "…"`.
4. **Блокер дольше 15 минут** — в #blockers с ID задачи и тем, кого ждёте; `tools/tasks.py set ID BLOCKED --blocker … --blocker-owner …`.
5. **Своими файлами владеет один человек** (`python3 tools/tasks.py owner PATH`). Чужой файл — только через владельца или его заместителя (A↔D, B↔C, E↔F).
6. **Заморозки:** контракты v1 — Сб 11:00; функции — Вс 11:00 (IC-3); код — Вс 13:00 (тег v1.0); подача — Вс 13:30 (или по ответу организаторов, но не позже чем за 3 часа до 23:59).
7. **Несовершеннолетние:** никаких имён, лиц и голосов в коммитах, скриншотах, видео и текстах; вечерняя работа только дома и до 23:00.
