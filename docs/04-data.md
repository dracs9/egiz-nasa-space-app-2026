# 04 · Данные

## Принципы

- Перед сравнением согласуем масштаб участков, разрешение данных, координаты и единицы.
- Метрики считаем одинаково для Земли, Луны и Марса и на одном разрешении. Иначе уклоны несравнимы.
- Пропуски показываем отдельно.
- Рейтинг означает относительное сходство среди рассмотренных кандидатов, а не вероятность пригодности.
- Для каждого вывода указываем источник.

## Земля

Почти всё доступно в Google Earth Engine.

| Данные | Чьи | Что считаем |
| --- | --- | --- |
| NASADEM, Copernicus DEM | NASA, ESA | Уклоны, перепад высот, шероховатость |
| MODIS LST | NASA | Температура поверхности: минимум, максимум, амплитуда |
| GPM IMERG | NASA, JAXA | Осадки и сухость |
| ASTER | NASA, Япония | Состав пород по тепловому ИК |
| Landsat 8/9 | NASA, USGS | Снимки, минеральные индексы, ряд снимков по Аралу |
| ESA WorldCover, MODIS NDVI | ESA, NASA | Маска голой поверхности без растительности |
| VIIRS Black Marble, GPW | NASA, NASA SEDAC | Удалённость и логистика |
| Геологические карты и статьи | Публикации | Породы: теги от геолога со ссылкой на источник |

## Подложки для карты и списки объектов

- Moon Trek и Mars Trek от NASA JPL: готовые карты-подложки через WMTS ([api.nasa.gov](https://api.nasa.gov/)).
- Earth Impact Database: список ударных кратеров Земли.
- Global Volcanism Program: список вулканов.
