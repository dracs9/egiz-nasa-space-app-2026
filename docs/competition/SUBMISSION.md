## 3. Требования к демо

| Требование | Как выполняем |
| --- | --- |
| Видео ≤ 30 с **или** ≤ 7 слайдов, включая титульный | Основное (P0) — 7 слайдов (STORY-03 черновик, STORY-06 числа и экспорт), они же для питча; видео 30 с — P1 (STORY-05), подаём, только если успели (DEC-017) |
| Видео с английскими субтитрами; слайды на английском | Вшитые субтитры + файл SRT |
| Публичная ссылка без пароля, разрешения и регистрации | Проверка в инкогнито |
| Шаблон гайда для видео начинается с «назовите себя и команду» | Для несовершеннолетних — только титр с названием команды, без имён, лиц и голосов |
| На слайдах гайд просит название команды, имена участников, челлендж | Название команды и ники вместо имён (правило о несовершеннолетних важнее); уточнить у организаторов в PREP-01 |
| ИИ-картинки и видео — видимая пометка «AI-generated», без символики NASA | SUB-04 |
| Музыка и картинки — свои или со свободной лицензией, с указанием источника | `submission/references.md` |

Структура слайдов, сценарий питча и раскадровка видео — [SIGNATURE_DEMO §3–5](../product/SIGNATURE_DEMO.md).

## 6. Советы прошлых победителей

- **Данные NASA обязательны.** Недостаточно сделать крутое приложение или игру: эксперт NASA должен увидеть использование открытых ресурсов NASA.
- **Демо — 30 секунд или 7 слайдов.** В старом гугл-доке было «2-минутное видео» — это неверно. Судьи смотрят сотни проектов, поэтому видео и первый абзац страницы сразу объясняют суть.
- **Рабочее демо, а не просто слайды.** Даже минимальный рабочий прототип оценивается выше презентации.
- **Не изобретать велосипед:** честно показать, что уже есть (NASA Planetary Analog Explorer), и чем мы лучше.
- **Тщательно заполнить форму:** открытый GitHub, рабочая ссылка на сайт, качественные скриншоты.
