## 1. Что и зачем

**Что.** Вы измеряете цели — Mons Mouton у южного полюса Луны (DEM NASA PGDA, 5 м) и кратер Jezero на Марсе (MOLA/HRSC, 200 м) — той же функцией рельефа и на тех же базах NASA, что и Землю; считаете положение Солнца и окна низкого Солнца; делаете панели кампании (главный ответ продукта), README для жюри и раскрытие ИИ. В S2 — тени и картинки «То же Солнце».

**Зачем.** Без целей нет сравнения; доступ к планетарным DEM — самый рискованный шаг субботы (PLNT-01, флаг HIGH_RISK), поэтому он первый. **Отвечаю за:** ворота G-C (решение по данным целей до 13:30), точность Солнца (E1), README для жюри.

## 5. Интерфейсы, которые я реализую

**Функции** ([FUNCTION_SPECIFICATIONS §2, §5](../engineering/FUNCTION_SPECIFICATIONS.md)):

```python
sun.sun_position(lat_deg, lon_deg, t_utc) -> (h_deg, az_deg)              # массивы; NOAA, с рефракцией
sun.lowsun_windows(lat_deg, h_max_deg, year=2025, step_min=10) -> (H_low[12], A_low[12])
sun.h_max_moon(lat_deg) -> float                                          # (90 − |lat|) + 1.54; −85° → 6.54
access.read_window(product, lon, lat, half_m, body) -> (z, transform, crs)  # окно GeoTIFF/COG, путь или URL
access.to_local_grid(z, transform, crs, center, body, p, half_m) -> z_local  # AEQD с радиусом тела, average
targets.build_targets(curated_csv, out_path) -> Path                      # → data/processed/targets.json
```

**`targets.json`** (`egiz.targets`): атрибуты цели с теми же ключами, что у Земли (`precip_mm = 0`, `bare_frac = 1` по определению), `attr_sources` для каждого значения (`computed:<продукт>` или ключ из `sources.csv`), `h_max_deg` для Луны. **`sun_windows.json`** (`egiz.sun_windows`): `lat_bins` (1 800 полос по 0,1°) и для каждой цели Луны матрицы `hours_low[полоса][месяц]` и `sweep_deg[полоса][месяц]` — формат в [API_AND_SCHEMA_CONTRACTS §2.4](../engineering/API_AND_SCHEMA_CONTRACTS.md). Окна зависят только от широты, поэтому файл не ждёт данных Земли.

**Панели кампании** (`web/src/components/campaign/`): `ObjectivesPanel` (полоса покрытия задачи и отметка «Earth ceiling»), `Frontier` (k = 1…3), `CampaignCard` (покрытие, площадки, роли, лучший месяц), `GapLedger` (атрибутные и физические разрывы с альтернативами и источниками). Все числа — из `results.runs[…].campaigns` и `gaps` через store; пустое состояние «No eligible Earth site (reason)».
