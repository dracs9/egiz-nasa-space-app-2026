## 2. Сигнатурное взаимодействие

| Шаг | Что происходит |
| --- | --- |
| 1. Действие | На Brief выбрать **Mons Mouton** (кандидатный район NASA у южного полюса) и шаблон **Moon base ops**, k = 3, нажать «Design campaign» |
| 2. Цель | Участок PGDA 20 (Leibnitz beta plateau = Mons Mouton), DEM LOLA 5 м → 50 м |
| 3. Данные | `targets.json` (атрибуты цели на базах 100 м и 2 км, h_max), `earth_candidates.json` (~3 000 кандидатов с атрибутами), `results.json` (F_o, кампании), `sun_windows` |
| 4. Алгоритм | F_o для 5 задач → короткий список (≤ 120) → точный перебор k = 1–3 → сверка жадным поиском → реестр разрывов |
| 5. Промежуточно | Фронт k: C₁ → C₂ → C₃ видно сразу |
| 6. Результат | Карточка: «Coverage [C₃] with 3 sites» — площадка 1 (рельеф: посадка и LTV), площадка 2 (низкое Солнце, лучший месяц [M]), площадка 3 (холодный сухой реголит) |
| 7. Визуализация | Карта Земли с тремя маркерами, полосы покрытия с засечкой «Earth ceiling», блок «Earth cannot test» |
| 8. Интерпретация | «Ни одно место на Земле не покрывает задачи Mons Mouton целиком. Три места вместе дают [C₃]. Освещение и холод Земля даёт только частично. Вакуум и 0,165 g — только в лаборатории» |
| 9. Доказательство | Evidence: E1 (Солнце совпадает с эталоном до [Δ]°), E4 (оптимизатор точен), E3 (места практики NASA на [pct] % — или честное «не подтвердилось») |
| 10. Ограничения | Сходство ≠ пригодность; снег не учтён (P0); рассеянный свет; разрешение DEM |

**Чем это не похоже на обычную карту:** ответ — не «похожие места», а решение «какие 2–3 места и когда», с ролями, количественным покрытием и списком того, чего Земля не даёт. Освещение считается по датам и рельефу, а не угадывается по фотографии.

**Самая сильная визуально и научно осмысленная функция:** «То же Солнце» (P1) — Mons Mouton и площадка 2 рядом, одна и та же высота Солнца, вращение азимута, совпадающие длинные тени. Если P1 не готов — тот же смысл передаёт календарь окон низкого Солнца в панели площадки (P0).
