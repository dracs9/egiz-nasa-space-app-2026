# Полная спецификация продукта Egiz v2

Владельцы: MEMBER_F (продукт и тексты), MEMBER_A (интерфейс), MEMBER_D (научные компоненты). Экраны — [SCREEN_BY_SCREEN_SPEC](SCREEN_BY_SCREEN_SPEC.md); стиль — [DESIGN_SYSTEM](DESIGN_SYSTEM.md); демо — [SIGNATURE_DEMO](SIGNATURE_DEMO.md). Это проект: интерфейс создаётся с 14.11 09:00.

## 1. Назначение

**Одна главная задача продукта:** по выбранной цели (район базы у южного полюса Луны или место на Марсе) и задачам миссии спроектировать наименьшую кампанию испытаний на Земле — где и когда — и показать, что Земля не даёт.

**Что должен понять судья за первые 10 секунд** (первый экран после клика «Design campaign»):

1. Слева — задачи миссии с полосами покрытия.
2. В центре — карта Земли с 2–3 пронумерованными площадками.
3. Справа — карточка кампании: «Coverage 0.xx with 3 sites» и список «Earth cannot test».

## 2. Пользователи и их работа

| Пользователь | Что делает в Egiz | Что получает |
| --- | --- | --- |
| Планировщик аналоговой кампании (основной) | Выбирает цель и задачи, сравнивает 1, 2 и 3 площадки | Набор площадок с ролями, неделями и разрывами |
| Инженер подсистемы (ровер, посадка, освещение) | Смотрит одну задачу, кандидатов и значения атрибутов | Обоснованный короткий список и что измерить в поле |
| Учёный-рецензент, судья | Открывает Evidence | Метод, проверки, ограничения, источники |
| Местная аудитория (Казахстан) | Включает режим «Казахстан» (P1) | Какую долю кампании может взять страна |

## 3. Понятия в интерфейсе

| Термин (EN в интерфейсе) | Определение | Откуда |
| --- | --- | --- |
| Target | Район на Луне или место на Марсе | `targets.json` |
| Mission template | Набор задач испытаний с атрибутами и весами | `mission_templates.json` |
| Objective | Задача испытания (Landing, EVA, LTV mobility, Low-Sun ops, Cold regolith…) | там же |
| Attribute fidelity | Насколько атрибут кандидата соответствует цели, 0–1 | движок |
| Objective fidelity | Соответствие задачи, 0–1 (взвешенное геометрическое среднее) | движок |
| Campaign | 1–3 площадки, у каждой роль (задачи) и лучшее окно | движок |
| Coverage | Взвешенное среднее лучших соответствий по задачам в кампании | движок |
| Earth ceiling | Лучшее соответствие, достижимое где-либо на Земле | движок |
| Gap | Атрибут или условие, которое Земля не даёт, и чем его закрыть | `gap_alternatives` |

**Сходство и пригодность разделены явно.** Fidelity — про условия. Подписи «Suitability not assessed: access, permits, safety» и «Snow not assessed» (в P0) видны всегда.

## 4. Функции и решение «польза / усилия»

| Функция | Научная или пользовательская ценность | Усилия | Решение |
| --- | --- | --- | --- |
| Выбор цели и шаблона миссии | Задаёт вопрос | Н | **P0** |
| Карточка кампании k = 1, 2, 3 с ролями и покрытием | Главный ответ | С | **P0** |
| Полосы покрытия по задачам и потолок Земли | Видно, где кампания слаба | Н | **P0** |
| Реестр разрывов с альтернативами | Честность, Validity | Н | **P0** |
| Карта Земли с площадками и «тепловой картой» кандидатов для выбранной задачи | Где искать | С | **P0** |
| Панель площадки: атрибуты, значения цели и кандидата, источники | Объяснимость | С | **P0** |
| Окна низкого Солнца по месяцам для площадки | Ответ «когда» | Н–С | **P0** (только по датам) |
| Evidence: метод, эксперименты, ограничения, источники, ИИ | Доказательства | С | **P0** |
| «То же Солнце»: цель и площадка с одинаковым Солнцем, тени | WOW, научно осмысленно | С–В | **P1** |
| Матрица соответствия «площадки × атрибуты» | Глубина анализа | С | **P1** |
| Живой пересчёт кампании при изменении задач и весов (Web Worker) | Пользователь проверяет устойчивость сам | С | **P1** |
| Режим «Казахстан» | Локальная польза | Н | **P1** |
| Индикатор уверенности (интервалы) | Неопределённость | С | **P1** (VAL-03) |
| Календарь с учётом снега | Реалистичность окон | Н | **P1** (MOD10A1) |
| Досье площадки (PDF или печать) | Удобно для отчёта | Н | **P2** |
| Экспорт результатов (CSV и JSON) | Проверяемость | Н | **P2** |
| Профили высот и разрезы рельефа | Наглядно, но не меняет решения | С | **P2** |
| 3D-глобус и 3D-рельеф | Эффект без научной пользы | В | **P3** |
| Сравнение сценариев бок о бок | Повтор функции фронта k | С | Не делаем |

Не делаем: чат с ИИ, логины, сохранение на сервере, анимации без смысла.

## 5. Информационная архитектура

```text
/#/brief        Mission Brief: цель + шаблон + задачи → «Design campaign»
/#/campaign     Campaign Planner (главный экран)
  ├─ ?site=ID   панель площадки (боковая)
  ├─ ?obj=O2    фокус на задаче (карта кандидатов)
  ├─ ?k=2       размер кампании
  └─ ?lens=kz   режим «Казахстан» (P1)
/#/twin?site=ID      То же Солнце (P1)
/#/matrix            Матрица соответствия (P1)
/#/evidence          Метод и проверки
```

Состояние выбора хранится в адресе: ссылкой можно поделиться, её можно открыть офлайн на запасном ноутбуке.

## 6. Данные, которые видит пользователь

Все числа — из `data/processed/*.json` (контракты — API_AND_SCHEMA_CONTRACTS). При `synthetic: true` в любом файле — красная плашка «SYNTHETIC DEMO DATA — not NASA observations». Каждое значение атрибута открывается по клику: значение кандидата, значение цели, функция и допуск, источник набора, дата.

## 7. Нефункциональные требования

| Требование | Цель | Проверка |
| --- | --- | --- |
| Первая загрузка | ≤ 3 с на эмуляции 4G; данные ≤ 3 МБ gzip | DevTools, QA |
| Переключение задачи и раскраска карты | ≤ 200 мс для ~3 000 точек | Профилирование |
| Пересчёт кампании в браузере (P1) | ≤ 300 мс при \|U\| ≤ 120, k = 3 | Тест производительности |
| Работа без интернета | Всё, кроме подложки карты; подложка заменяется фоном | QA-03 |
| Доступность | Клавиатура, фокус, контраст AA, подписи к графикам | Lighthouse ≥ 90 |
| Ширина | 375–1920 px | Скриншоты |
| Язык интерфейса | Английский; тексты — в `copy.json` (MEMBER_F) | — |

## 8. Чего продукт не утверждает

- Что площадка «эквивалентна» Луне или Марсу или пригодна для испытаний без полевой проверки.
- Что кампания — глобальный оптимум (только «точно на коротком списке, сверено жадным поиском»).
- Что окна освещения воспроизводят лунный свет (на Земле есть атмосфера и рассеянный свет).
- Что это официальный инструмент NASA. В подвале: «Independent student project for NASA Space Apps Challenge 2026. Not affiliated with or endorsed by NASA.»
