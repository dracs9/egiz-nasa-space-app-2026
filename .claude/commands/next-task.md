Найди и выполни следующую задачу с наивысшим приоритетом.

1. Прочитай CLAUDE.md.
2. Запусти `python3 tools/tasks.py next $ARGUMENTS` (без аргумента — для всей команды).
3. Если участник не указан — покажи по одной верхней доступной задаче каждого участника и спроси, чью задачу выполнять. Соответствие людей и ID хранится вне репозитория.
4. Если участник указан — возьми верхнюю задачу из «В РАБОТЕ», иначе из «МОЖНО НАЧАТЬ», прочитай карточку (`python3 tools/tasks.py show ID`) и выполни её по протоколу CLAUDE.md §4: шаги, только свои файлы, тесты и проверки, доказательства, PROGRESS.md, коммит.
5. До 2026-11-14 09:00 по Астане — только PREP- и RULE-задачи; задачи из группы «ЖДЁТ РАЗРЕШЕНИЯ ОРГАНИЗАТОРОВ» не начинать.
6. Если доступных задач нет — объясни почему (время, зависимости, разрешения) и назови ближайшую задачу, которая откроется.
