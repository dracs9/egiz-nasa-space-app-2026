# Use of artificial intelligence

## Field text for the Space Apps project page (14 November 2026)

**Tools and what they did.** Claude and Claude Code (Anthropic) and Codex (OpenAI) assisted with planning, the Python data pipeline, the React/TypeScript application, tests and documentation; every change was run against the real data and the test suites, and the team reviewed and directed the work. Veo and Nano Banana (Google) were used only to draft cinematic landing-page clips on a separate, unmerged branch; any such media shipped is labelled "AI-generated", contains no NASA logos or insignia, and is captioned as an illustration, not data.

**No trained models in the product.** EGIZ's analysis is classical and inspectable: distribution distances and Monte Carlo uncertainty for similarity, unsupervised k-means terrain units, a Laplacian-of-Gaussian crater detector and a Mahalanobis anomaly screen. Foundation models (Prithvi-EO-2.0, TerraMind) are listed in the model registry only as incompatible with these inputs; they are not used.

**Optional assistant.** Discover has an optional research assistant. When enabled, a server-side language model (the API key stays on the server) may only call allow-listed tools that read the measured bundle; it is instructed never to state a number that did not come from tool output, and the offline mode answers with tool output alone. ASTRAL Mission Studio has the same allow-listed design but only runs if a viewer pastes their own key, which stays in their browser session. No result, measurement or citation in EGIZ was generated by an AI model.
