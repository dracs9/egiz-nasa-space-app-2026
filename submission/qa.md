# Questions and answers

**Why several sites?** Each site can rehearse some objectives better than others. Coverage uses the best site per objective.

**Is the solution globally optimal?** The engine enumerates its shortlist and compares full-pool greedy selection. It does not prove full-pool global optimality.

**Are the demo values NASA observations?** No. Measurements in the bundled fixtures are invented and permanently labelled.

**Can a team use these results in the field?** Scientific review, suitability, logistics, permissions, and safety remain separate requirements.

**Why laboratories?** Gravity, atmosphere, radiation, and regolith differences require separate testing facilities.

**Does AI calculate scores at runtime?** No. Scores and explanations follow deterministic code.

**Does it work offline?** Code and data work locally. Satellite imagery is optional; map/table fallback remains usable.
