# Seven-slide demo

1. Egiz: Earth campaigns for Moon and Mars tests. Independent software prototype.
2. Test objectives: landing hazards, field traverses, mobility, low Sun, cold and dryness.
3. Method: matched metric attributes, objective fidelity, a campaign of complementary sites.
4. Data: Python raster ingestion, NOAA lighting, planned NASA/ESA source adapters. Synthetic fixtures remain explicit.
5. Demo: select Mons Mouton, compare one to three sites, inspect per-objective roles and physical gaps. Every displayed fixture value is invented.
6. Evidence: software tests verify formulas, search, constraints, and reproduction. Real-data E3 and other scientific experiments remain not_run until performed.
7. Next external requirements: authenticated data acquisition, preregistration, independent scientific review, then field validation. No public deployment or competition submission yet.

This draft deliberately contains no unsupported scientific performance numbers. Use the current app for screenshots and keep the synthetic banner visible.
